# Projekt RL: Sterowanie agentem w grze unikania pocisków

Projekt realizowany w ramach przedmiotu **Uczenie się ze wzmocnieniem** (WEiP PRz 2026/2027).

## Autor
* Igor Paśko (177137)

## Opis projektu
Celem projektu jest zaprojektowanie, zaimplementowanie i przetestowanie agenta sterowanego algorytmem uczenia ze wzmocnieniem (RL), którego zadaniem jest unikanie nadciągających pocisków i maksymalizacja czasu przeżycia na planszy 2D.
